# CostSaver India

A responsive, privacy-first toolkit for smarter everyday money decisions in India.

## Included tools

- Monthly Budget Planner
- Commute Cost Calculator
- EMI & Loan Calculator

## Run locally

Open `index.html` in a browser. No dependencies or build step are required.
